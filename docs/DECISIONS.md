# Журнал решений

Формат: дата — решение — причина.

- 2026-11-06 — Приложение для одного пользователя, под его реальные цели. — Сначала проверить систему на себе.
- 2026-11-06 — Главная проблема: защищать фундаментальные цели от вытеснения новыми. — Результат «пяти почему» вверх и вниз.
- 2026-11-06 — Цикл: инкубатор → WIP → цели/майлстоны → трекер → ретро. — Каждый этап закрывает выявленную причину бросания.
- 2026-11-06 — Три уровня цели: направление, майлстон, действие; майлстон обязателен. — Опыт с английским: без цели практика бросается.
- 2026-11-06 — Пропуск без наказания, консистентность вместо стриков. — Стрики провоцируют бросание после срыва.
- 2026-11-06 — Минимальная версия действия = полкубика. — Плохой день не обнуляет движение.
- 2026-11-06 — Норма не повышается автоматически при отставании. — Давление «догонять» ведёт к бросанию.
- 2026-11-06 — Главный экран: матрица задачи × дни, цвет = категория, интенсивность = глубина. — Баланс с одного взгляда.
- 2026-11-06 — Палитра категорий фиксированная, без красного. — Читаемость и отсутствие ассоциации с ошибкой.
- 2026-11-06 — Слоты постоянны, наполнение меняется; ротация наборов по неделям. — Против монотонности без потери автоматизма.
- 2026-11-06 — Составные задачи (спорт): иконки видов, несколько в день, план/факт, замена = успех. — Баланс и планирование.
- 2026-11-06 — Хостинг: Docker на NAS; клиент — PWA на iPhone; доступ только через приватную сеть. — Доступ отовсюду без открытых портов.
- 2026-11-06 — AI — опциональный слой, не ядро. — Система должна работать без него.
- 2026-11-07 — Разработка: Claude Code интерактивно на NAS в контейнере `claude-dev` (не root, только `/volume3/dev`, без `docker.sock`, токен на один репозиторий); владелец управляет через Remote Control. Без cron и headless. — Владельцу нужен доступ с телефона, а не автоматизация; изоляция защищает данные NAS.
- 2026-11-07 — Деплой: агент пишет код и Dockerfile; compose для запуска принадлежит владельцу и лежит вне репозитория (`/volume3/docker/one-percent/`, только том `./data`, без privileged/host-network/сокета). DSM Task Scheduler раз в 5 минут: новый коммит в `main` → build → `up -d` только при успешной сборке → healthcheck, при провале откат на прежний образ; статус последнего деплоя пишется в файл в `/volume3/dev`. — Compose из репозитория дал бы агенту root на NAS.
- 2026-11-07 — Доступ с iPhone: Cloudflare Tunnel + Cloudflare Access (одноразовый код на почту) на отдельном домене; DNS `sna19.com` не трогаем. Заменяет «только через Tailscale». — Рабочий iPhone без VPN; Funnel открывает приложение публично с одним паролем; поддомены нужны для песочницы. *Заменено 2026-11-08: Funnel + Caddy, см. ниже.*
- 2026-11-07 — Стек v0.1: SvelteKit (adapter-node, TypeScript) + SQLite в одном файле на томе `./data` (better-sqlite3, миграции Drizzle в git); PWA через service worker: оболочка в кэше, офлайн-очередь отметок в IndexedDB. Отметка пишется как upsert по паре (practice, date), чтобы повтор из очереди не задваивал запись. Бэкап — `VACUUM INTO` скриптом, healthcheck — `/health`. — Мгновенный отклик на тап и работа без сети при истёкшей сессии Cloudflare Access; один язык. Выбрал владелец из вариантов A/B/C (канал, «Диалог»).
- 2026-11-07 — Сессия Cloudflare Access длинная (около месяца). — Вход по коду с почты должен быть редким. Поведение cookie Access в PWA с экрана «Домой» ещё не проверено: результат дописать сюда после проверки на iPhone. *Заменено 2026-11-08: Funnel + Caddy, см. ниже.*
- 2026-11-07 — Архитектура NAS: x86_64 (Intel Celeron J4125, ядро 4.4 DSM); базовый образ `node` на Debian (glibc). — Для better-sqlite3 есть готовые сборки linux-x64. Поправка от 2026-11-07: в Docker-сборке `npm ci` всё же компилирует модуль, поэтому в build-стадию добавлены python3, make и g++; в финальный образ они не попадают.
- 2026-11-07 — Seed v0.1: итальянский 5/15 мин, английский вслух 5/10 мин, HBR 1/3 стр, спорт 1/1 трен; категории «Развитие» (синий) и «Здоровье» (зелёный), по цели на практику. — Подтвердил владелец; в спеке дозы для языков не были заданы.
- 2026-11-07 — Два адреса приложения: https через Cloudflare (снаружи, рабочий iPhone) и http://100.75.53.22:3001 через Tailscale, как у openGym (порт 3000 занят им). Встроенная проверка источника форм SvelteKit заменена своей: хост из Origin должен совпадать с хостом запроса, схема не важна. — Встроенная проверка требует один https-адрес и отклоняла настройки по http. Офлайн-открытие работает только по https: service worker браузер запускает только в защищённом контексте. *Адреса заменены 2026-11-08: один https-адрес через Funnel + Caddy, http по Tailscale-IP закрыт. Проверка «тот же хост» для форм остаётся.*
- 2026-11-08 — Внешний доступ ко всем приложениям NAS: Tailscale Funnel + Caddy-замок, отдельное имя на приложение через sidecar-контейнер Tailscale (`tracker.morray-iguana.ts.net`, позже `yael.…`; openGym остаётся на `sna19n.morray-iguana.ts.net`). Приложение публикуется на хосте только на `127.0.0.1`, снаружи доступно лишь через замок. Заменяет решения «Cloudflare Tunnel + Access» и «длинная сессия Access» от 2026-11-07 и адрес по http через Tailscale. — VPN нельзя поставить ни на рабочий iPhone, ни Яэль; отдельный origin на приложение изолирует cookie, хранилище и PWA и даёт каждому человеку свой пароль; схема уже работает у openGym (включая cookie для iOS PWA); без домена, трафик расшифровывается только на NAS. Цена: вход по паролю без защиты от перебора — пароли длинные случайные.
- 2026-11-08 — Строка главного экрана = цель (раскрывается в практики); вторая линза — по формату (сущность Format, у практики необязательна); счёт дня всегда по целям. — Первый день использования: восемь строк и «2/8» демотивируют, а альтернативы (тренажёрка/аэробика) делали полный день недостижимым. Spec 002, выбрал владелец.
- 2026-11-08 — Перед применением миграции схемы приложение само копирует файл базы в `data/backups/pre-migration-<время>.db`. — Данные пользователя — ценность; доступа к боевой базе у агента нет, откат должен быть возможен без него.
- 2026-11-08 — Перегруппировка практик по Spec 002 сделана владельцем вручную в настройках, без миграции данных кодом. — Настройки уже позволяли выбрать цель, имя и формат практики; агент не видит боевую базу, а миграция по именам вслепую рискованна.
- 2026-11-09 — Трекер отвечает на «как я двигаюсь?», а не «что сделать?»: напоминания и уведомления не строим, интегрируем «Напоминания» и Shortcuts (уведомление о времени — в «Напоминаниях», отметка из уведомления — через Shortcut). Расписание задач (допустимые дни) — только для честной оценки и экрана. — Принцип владельца: не дублировать то, что iPhone уже делает хорошо; фокус приложения — заметить затухание движения.
