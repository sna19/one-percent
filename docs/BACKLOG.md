# Бэклог

Принцип: каждый этап — рабочее приложение, которым владелец пользуется ежедневно. Следующий этап — после недели реального использования и ретро.

## v0.1 — ежедневное ядро (MVP)
- [x] Выбор стека, запись в DECISIONS.md; docker compose; бэкап данных
- [ ] Категории с цветом из палитры
- [ ] Цели (только active) с направлением и текущим майлстоном (текстом)
- [ ] Практики: единица, минимум, норма, ежедневный ритм
- [x] Отметка в одно касание (минимум / норма / количество)
- [x] Главный экран: недельная матрица, глубина цвета, «N дней без», подсказка приоритета
- [x] PWA для iPhone, светлая/тёмная тема

Проверка на себе: итальянский, английский вслух, книга (HBR: 1 книга за квартал, 1–3 стр/день), спорт.
