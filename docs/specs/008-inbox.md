# Spec 008 — Входящие: быстрая запись и разбор

Копия вкладки «Spec 008» рабочего канала (2026-11-15).

## Проблема

Шаг навыка, идея или новая задача приходят спонтанно, посреди дня. Сейчас, чтобы записать мысль, нужно сразу решить, к какой практике она относится, открыть её заметку и найти место. Пока решаешь, мысль уходит.

## Решение

Записать и разобрать — два разных действия в разное время (принцип «входящих» из GTD).

- **Записать** за одно касание, без единого выбора.
- **Разобрать** потом, в спокойной обстановке: привязать к практике, дню, цели или удалить.
- Входящие — **не второй список дел**: из них ничего не выполняют, их только разбирают.

## Навигация

- Нижняя панель: **«Входящие» — первая вкладка слева**, затем «Сегодня», «Неделя», «Всё». На иконке счётчик неразобранных записей (без красного).
- Приложение по-прежнему открывается на «Сегодня» (решение Spec 004); тап по «Входящим» — один тап от любой вкладки.
- **Кнопка «+»** в верхней панели на всех корневых экранах открывает быструю запись. На «Входящих» поле записи стоит прямо вверху списка.

## Быстрая запись

- Лист снизу с одним многострочным полем, фокус и клавиатура сразу; кнопка «Готово» и Enter+Cmd сохраняют, свайп вниз сохраняет непустой текст (запись не теряется случайно).
- Никаких обязательных полей. Сохраняются текст и время создания.
- После сохранения — короткое подтверждение «Во входящих», пользователь остаётся там, где был.
- Работает без сети: запись встаёт в ту же офлайн-очередь, что и отметки.

## Разбор

Список записей, новые сверху: текст (первый абзац целиком), «когда записано». Тап по записи открывает её с действиями:

| Действие | Что происходит |
| --- | --- |
| В заметку практики | выбор практики деревом (как в настройках) → текст дописывается в конец постоянной заметки **пунктом чеклиста** |
| В заметку дня | выбор дня (сегодня, завтра, дата в пределах спланированных недель) и практики → дописывается пунктом чеклиста в заметку дня; если практики нет в плане этого дня — предложить добавить |
| Новая практика | форма создания практики, название = первый абзац, остальной текст — в постоянную заметку; цель выбирается деревом |
| Новая цель | форма цели, название = первый абзац, текст — в описание; при появлении инкубатора — сюда же статус «в инкубаторе» |
| Сделано | запись закрывается (мысль на две минуты — сделал сразу) |
| Удалить | запись удаляется |

- После действия запись уходит из списка; закрытые и разобранные хранятся в истории 30 дней (одна строка внизу «История»), с возможностью вернуть.
- Текст записи можно поправить до разбора.
- Свайп по записи влево — «Удалить», вправо — «Сделано» (быстрая чистка).

## Против кладбища

- **Воскресное планирование начинается с входящих:** если есть неразобранные, на экране плана недели сверху плашка «Во входящих N записей — разобрать» со ссылкой.
- Записи старше 14 дней мягко подсвечиваются (приглушённая метка «2 нед»), без красного и без уведомлений.

## Модель данных

| Сущность | Поля | Заметки |
| --- | --- | --- |
| InboxItem | id, text (формат редактора из Spec 005), created_at, updated_at, status (`open` / `done` / `processed` / `deleted`), closed_at, target (куда разобрано, для истории) | миграция с резервной копией |

## Критерии приёмки

- [ ] С любой корневой вкладки «+» → текст → «Готово» укладывается в 5 секунд на iPhone; клавиатура поднимается сразу.
- [ ] «Входящие» — первая вкладка со счётчиком; приложение открывается на «Сегодня».
- [ ] Каждое из шести действий разбора работает; дописанный пункт виден в заметке практики или заметке дня как пункт чеклиста.
- [ ] Запись, сделанная без сети, появляется после восстановления связи.
- [ ] На экране плана недели есть плашка неразобранных; записи старше 14 дней помечены.
- [ ] Разобранное видно в «Истории» 30 дней и возвращается во входящие.

## Вне объёма (позже)

- **Shortcut / Siri** для записи во входящие из любого места iPhone — требует отдельного способа входа через замок Caddy; отдельная спека.
- Шаг проекта как цель разбора — когда появятся проекты.
- Теги, приоритеты, напоминания у записей.
