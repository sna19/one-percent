# Spec 010 — Итоги недели

Копия вкладки «Spec 010» рабочего канала (2026-11-16).

## Проблема

Прогресс сейчас виден только строкой «по плану X из Y» и недельной сеткой. Нет ответа на вопрос «что мне нужно знать о прошедшей неделе». При этом целей много, и одна большая картина по всем целям нечитаема.

## Принципы

- **Управление по исключениям.** Подробно показывается только то, что отклонилось от обычного. Всё, что идёт нормально, сворачивается в одну строку «В норме: N целей».
- **Не больше трёх строк в блоке**, остальное за «ещё N».
- **Сравнение только с собой** (среднее за 4 прошлые недели), без красного, без стриков.
- **Каждая цифра ведёт к решению**, иначе её нет на экране.
- Экран читается за минуту.

## Где живёт

- Экран «Итоги недели» — второй шаг воскресного ритуала: **входящие → итоги → план новой недели**. Кнопка внизу «Перейти к планированию».
- Открывается из «Недели»: меню «⋯» → «Итоги недели» (с выбором прошлых недель) и плашкой на первом дне новой недели «Итоги прошлой недели готовы», пока они не просмотрены.
- Итоги считаются по данным, не хранятся; хранится только ответ на ретро.

## Фокус недели

- При планировании недели можно отметить **до трёх целей как фокус** (поле у WeekPlan). Это цели, ради которых неделя планируется.
- В итогах фокусные цели показываются всегда и подробно (блок «Фокус» самым первым), остальные — только если попали в исключения.
- Фокус необязателен; без него блока «Фокус» нет.

## Блоки экрана (в этом порядке)

| # | Блок | Что показывает | Правило отбора |
| --- | --- | --- | --- |
| 0 | Прошлое решение | ответ на ретро прошлой недели и вопрос «Сработало? да / частично / нет» | если ответ был |
| 1 | Фокус | фокусные цели: по плану X из Y, темп к майлстону | если фокус задан |
| 2 | Что затухает | цели, где за неделю сделано меньше половины среднего за 4 недели, или запланированное выполнено на 0 | сортировка по силе просадки, максимум 3 |
| 3 | План | «По плану X из Y · бонусов Z», полоса; ниже строка по категориям (Развитие 80% · Здоровье 60% …); тап по категории раскрывает её цели | всегда, категории свёрнуты |
| 4 | Майлстоны | майлстоны с отставанием от темпа или сроком в ближайшие 2 недели (фокусные уже в блоке 1) | максимум 3; без майлстонов блока нет |
| 5 | Реалистичность плана | выполнение плана по дням недели (7 столбиков); фраза о слабых днях (< 50%) и о практиках, что 3 недели подряд выполняются меньше чем наполовину | слабые дни — серым, не красным |
| 6 | Куда ушло время | сумма минут по форматам (слоёная полоса) и одна фраза о перекосе | только практики в минутах; форматы без минут не показываются |
| 7 | В норме | одна строка «В норме: N целей», тап раскрывает список | всё, что не попало в блоки 1, 2, 4 |
| 8 | Ретро | «Что изменишь на следующей неделе?» — текстовое поле и кнопка «Перейти к планированию» | поле необязательное |

- Пока истории меньше 4 недель, среднее считается по тому, что есть; если истории нет — блок «Что затухает» опирается только на план.
- Каждый блок начинается одной фразой-выводом, затем визуал. Пустой блок не показывается.

## Сигнал перегруза

Если в блок «Что затухает» попало больше трёх целей или в плане было больше мягкого лимита практик — под блоком одна фраза: «Активных целей N. Может, часть поставить на паузу?» со ссылкой в настройки. Без настаивания, не чаще раза в неделю.

## Ротация: пауза по плану

Владелец чередует недели: **ядро** (цели каждую неделю) + **набор A** или **набор B**. Наборы реализуются шаблонами недели («Неделя A», «Неделя B»), новая сущность не нужна.

- **Цель без практик в плане недели — на паузе по плану.** Она не попадает в «Что затухает» и в «В норме»; в итогах — одна строка «На паузе по плану: N целей».
- **Среднее за 4 недели** для «Что затухает» считается только по неделям, когда цель была в плане. Иначе ротация делает каждую цель «просевшей вдвое».
- Пауза по плану **останавливает счётчик «N дней без»** и не влияет на «В приоритете».
- **Режим поддержки:** практики целей на паузе видны в «Сделать что-то ещё» как обычно; сделанное — бонус и в итогах помечается «поддержал на паузе», без обязательств.
- В фокус недели можно выбрать только цели, есть в плане этой недели.

Критерий: в неделю B цели набора A не попадают в «Что затухает», а в неделю A сравниваются с прошлыми неделями A.

## Критерии приёмки

- [ ] Итоги прошлой недели помещаются на iPhone не больше чем в два экрана прокрутки при реальных данных владельца (10+ целей).
- [ ] В блоках не больше трёх строк; нормально идущие цели свёрнуты в «В норме».
- [ ] Фокус задаётся при планировании и показывается первым блоком.
- [ ] Ретро-ответ сохраняется и через неделю показывается с вопросом «Сработало?».
- [ ] Воскресный поток входящие → итоги → план проходится подряд без поиска кнопок.
- [ ] Нигде нет красного и стриков; светлая и тёмная тема читаемы.

## Вне объёма

Месяц, квартал, год, тепловые карты и процент консистентности (следующий слой); экспорт данных; AI-комментарии к итогам.
