# Spec 013 — вкладка «Цели» и образ цели

Копия вкладки «Spec 013» рабочего канала (2026-11-16), в сокращении.

## Зачем
Цели — смысл всего приложения, но у них нет своего места: они рассыпаны по настройкам и подписям карточек. Нужно одно красивое, воодушевляющее место со всеми целями и визуальный образ у каждой цели.

## Принцип геймификации
Награда — только настоящее: вложенное время и достигнутые майлстоны. **Нет** очков, уровней, стриков и красного.

## Часть A — образ цели
- Поле цели «Образ»: тип (`icon` / `emoji` / `text`) и значение. Фон образа — цвет категории.
- Выбор на экране цели: лист с вкладками «Иконки» (~60 линейных иконок по группам), «Эмодзи» (одно эмодзи), «Текст» (1–3 символа).
- По умолчанию — текст из первых двух букв названия.
- Маленькая метка (16–20 pt): строки целей в «Неделе», «Всё», дерево настроек, шапка экрана цели. На карточке «Сегодня» — нет.

## Часть B — вкладка «Цели»
- Нижняя панель: «Входящие · Сегодня · Неделя · Цели · Всё». Пять — максимум.
- Крупный заголовок «Цели»; секции категорий в порядке настроек; горизонтальная лента карточек со scroll-snap (карточка ~220 pt).
- Карточка: образ 52 pt; название; «Зачем» курсивом до двух строк (пусто — «добавь, зачем»); флажок + майлстон + срок (пусто — «нет майлстона»); полоса прогресса майлстона (без бюджета — нет); 7 точек недели (день закрашен, если хоть одна практика цели ≥ минимума; на паузе по плану — бледные и «на паузе»); «Вложено …» за всё время (все практики в минутах — часы, иначе дни с отметкой ≥ минимума; никогда не уменьшается); флажок с галочкой + число достигнутых майлстонов (0 — нет).
- Тап по карточке — экран цели; «‹ Цели» возвращает на ту же карточку.
- В верхней панели: новая цель; «?» — справка.
- Последняя лента «Пройденный путь» (если есть): цели из архива, приглушённые, с датой и «вложено». Свёрнута по умолчанию.
- Пустое состояние: «Создай первую цель» с кнопкой.

## Модель данных
Goal + образ: image_kind, image_value. Миграция с резервной копией; существующим целям — `text` с первыми двумя буквами названия.

## Критерии приёмки
- [ ] Вкладка «Цели» — четвёртая; ленты плавно листаются и останавливаются на карточке.
- [ ] Образ задаётся иконкой, эмодзи или текстом и виден в галерее, на экране цели и в строках целей.
- [ ] Тап по карточке → экран цели → «‹ Цели» возвращает на ту же карточку.
- [ ] «Вложено» и точки недели считаются по правилам; цели на паузе по плану помечены.
- [ ] Нет очков, уровней, стриков и красного; обе темы читаемы.

## Вне объёма
Свои картинки/обложки, анимации роста, перетаскивание целей на этом экране.
