# Spec 007 — навигация, настройки, шаблоны недели

> Копия вкладки «Spec 007» рабочего канала (https://claude.ai/artifact/17433pk2Ek3UGUh1LBUofq), снята 2026-11-14 (rev 5). Сокращённый пересказ; полный текст — в канале.

Порядок работ: A → B → C → D → E → F, маленькими коммитами. Решения — в `docs/DECISIONS.md`.

## Проблемы
- Управление экранами разнородное: вкладки сверху, ссылки внизу, «Порядок» отдельной кнопкой, стрелки в одних списках и перетаскивание в других.
- Настройки — пять плоских списков; не видно, какая практика в какой цели и цель в какой категории.
- У шаблонов два имени; шаблон нельзя перезаписать.

## Часть A — единая навигация
- **Нижняя панель вкладок** «Сегодня», «Неделя», «Всё»: иконка + подпись, учитывает safe area.
- **Верхняя панель — один компонент:** слева «‹ <предыдущий экран>» на вложенных экранах; крупный заголовок, при прокрутке сжимается в компактный по центру; панель липкая, полупрозрачная; справа до двух иконок + «⋯» с меню.
- Иконки без текста — только однозначные (шестерёнка, «+», карандаш, ≡), у каждой `aria-label`; меню — один уровень.

| Экран | Иконки | Меню «⋯» |
| --- | --- | --- |
| Сегодня | ≡ «Порядок», шестерёнка | Изменить план |
| Неделя | карандаш «Изменить план», шестерёнка | Шаблоны недели, Новая неделя с нуля |
| Всё | переключатель «Цели / Форматы», шестерёнка | — |
| Настройки | «+» | Архив, Старые настройки |
| Практика / цель | — | В архив |

- Ссылки «Изменить план» и «Настройки» внизу экранов убираются. Одна библиотека линейных иконок, зона касания ≥ 44 pt.

## Часть B — перетаскивание везде
Сортировка — только перетаскиванием за ≡; стрелки убираются отовсюду. В настройках — без отдельного режима; в «Сегодня» — через режим «Порядок».

## Часть C — новые настройки
- Дерево: категории (цветная метка) → цели (сворачиваются) → практики (название, формат, доза «5 / 10 мин»).
- Тап по практике или цели — отдельный экран редактирования «‹ Настройки», автосохранение. Практика: название, цель, формат, единица, минимум, норма, дни по умолчанию, два флага Spec 006, постоянная заметка.
- «+ Практика» в конце цели, «+ Цель» в конце категории; «+» в панели — меню «Практика / Цель / Категория / Формат».
- Перетаскивание: порядок, перенос практики в другую цель, цели в другую категорию.
- Внизу справочники «Категории» и «Форматы» (свои экраны), строка «Архив».
- Лимит практик и шаблоны уходят на экран плана (D).
- Старые настройки остаются: «⋯» → «Старые настройки» (`/settings/legacy`), без изменений.

## Часть D — шаблоны недели
- Одно имя: «шаблон недели»; «план» — конкретная неделя.
- «Сохранить как шаблон недели» → «Новый шаблон» (имя) или «Заменить: <имя>» (с подтверждением; id и имя сохраняются, содержимое меняется, включая заметки дней).
- Экран плана, «⋯» → «Шаблоны недели»: список, переименование, удаление (архив), порядок перетаскиванием; там же «Мягкий лимит практик в плане».

## Часть E — «Сегодня» листается по дням
- Заголовок: «Сегодня», «Завтра», дальше «Пн, 16 ноября»; «‹ ›» и свайп; на другом дне — кнопка «Сегодня».
- Будущий день: карточки плана с заметками дня; заметку дня можно писать, практику добавить в план дня или убрать; отметки недоступны; «Сделать что-то ещё» скрыто.
- Прошедший день: отметки и галочки задним числом можно, состав плана менять нельзя.
- Диапазон: текущая и следующая неделя; переход на неспланированную следующую создаёт черновик.
- Нижняя вкладка «Сегодня» всегда возвращает на сегодня.
- Критерий: вечером «Сегодня» → «›», план питания на завтра без редактора недели; утром он на карточке, галочки работают.

## Часть F — тап раскрывает, отметка только чекбоксом
Заменяет правило Spec 004 «тап по карточке ставит норму».
- Чекбокс слева — единственная отметка (тап — норма, повторный — снять), зона касания ≥ 44 pt.
- Тап по остальной карточке раскрывает её на месте (одна раскрытая за раз): постоянная заметка целиком с галочками, заметка дня, строка дозы «Минимум / Норма / Количество…», ссылки «Изменить заметку» и «Изменить заметку дня».
- Повторный тап сворачивает. Долгое нажатие убирается; «⋯» остаётся.
- У практик «по чеклисту» чекбокса нет; тап раскрывает. На будущем дне чекбокс неактивен.

## Критерии приёмки
- [ ] Одна верхняя панель на всех экранах; «‹» на вложенных; заголовок сжимается при прокрутке.
- [ ] Нижняя панель на корневых экранах, не перекрывается жестовой полосой.
- [ ] Ни одной стрелки сортировки; перетаскивание в «Сегодня» и во всех списках настроек.
- [ ] Дерево настроек; отдельный экран практики; «+ Практика» создаёт её в нужной цели.
- [ ] «Старые настройки» открываются из меню и работают.
- [ ] «Шаблон недели» везде; шаблон можно заменить текущим планом и удалить.
- [ ] Все иконки с `aria-label`; обе темы читаемы.
- [ ] (E) план питания на завтра из «Сегодня» → «›».
- [ ] (F) тапы по карточке не ставят отметку; отметка только чекбоксом; раскрытая карточка показывает полную заметку и выбор дозы.
