# Spec 006 — план дня: заметка на день и отметка по чеклисту

> Копия вкладки «Spec 006» рабочего канала (https://claude.ai/artifact/17433pk2Ek3UGUh1LBUofq), снята 2026-11-13 (rev 1).

## Как пользоваться этой спекой

Задача для Claude Code после Spec 005: использует её редактор и лист и план из Spec 003. Сохрани спеку в `docs/specs/006-day-plan.md`, работай маленькими коммитами, решения — в `docs/DECISIONS.md`.

## Проблема

Для снижения веса владелец планирует питание на неделю: по три–четыре трапезы в день и отдельно вечер. План у каждого дня свой, а постоянная заметка практики (Spec 005) одна на все дни: пришлось бы переписывать её каждый день и вручную снимать галочки. Для такой практики важен не выбор дозы, а сколько пунктов плана выполнено.

## Решение

- **Заметка дня:** у каждой записи плана (практика + дата) может быть своя заметка. Один лист на весь день, свободный текст в том же редакторе, что в Spec 005 (буллиты, чеклисты, форматирование). Никаких отдельных объектов для трапез или пунктов.
- **Показ целиком:** настройка практики «показывать заметку целиком»; заголовок такой заметки на карточке — «План дня».
- **Отметка по чеклисту:** настройка практики, при которой глубина кубика считается сама по галочкам заметки дня.
- **Обнуление без ручной работы:** каждая неделя — новые копии заметок с чистыми галочками.

## Модель данных

| Изменение | Поля | Заметки |
| --- | --- | --- |
| PlanItem + note | note, note_updated_at | формат как у заметки практики из Spec 005 |
| PlanTemplate: заметки | заметка у элемента шаблона (практика + день недели) | хранится без отмеченных галочек |
| Practice + show_note_full | bool, по умолчанию выключено | «показывать целиком» |
| Practice + checklist_marks | bool, по умолчанию выключено | «отметка по чеклисту» |

Миграция без потери данных, с резервной копией как раньше.

## Отметка по чеклисту

Работает, если у практики включена настройка и в заметке дня есть хотя бы один пункт с галочкой. Обычный текст и буллиты на счёт не влияют.

| Отмечено пунктов | Глубина | Запись Entry |
| --- | --- | --- |
| все | 1 (полный кубик) | amount = norm_dose |
| половина и больше | 0.5 | amount = min_dose |
| меньше половины | 0 | записи нет |

- Запись создаётся и обновляется автоматически тем же безопасным «записать или обновить» по паре практика + дата, поэтому счёт дня, неделя, «Всё» и «N дней без» работают без изменений.
- У такой практики на карточке нет квадрата отметки и выбора дозы; вместо них счётчик «3 из 5».
- Если в заметке дня нет пунктов с галочкой или заметки нет — практика работает как обычная, с ручной отметкой.

## Карточка «Сегодня»

- Есть заметка дня — на карточке показывается она (целиком или первой строкой по настройке). Нет — первая строка постоянной заметки практики, как в Spec 005.
- При показе целиком форматирование сохраняется (цвета, жирный, буллиты).
- **Галочки отмечаются прямо на карточке** одним тапом, без открытия редактора; отмеченный пункт зачёркивается.
- **Тап по тексту заметки** открывает лист с редактором заметки дня. Отметка практики для обычных практик — по квадрату слева. Редактирование текста внутри карточки не делаем: на телефоне это случайные правки при прокрутке.
- В листе есть переход к постоянной заметке практики (общие правила, неизменное).
- У бонусной практики (вне плана) заметки дня нет: заметка дня живёт только в плане.

## Планирование

- В редакторе плана: тап по пустой клетке — запланировать; тап по запланированной — меню «Заметка дня» / «Убрать из плана». Клетка с заметкой помечена небольшой иконкой.
- Убрать из плана день с непустой заметкой — только с подтверждением.
- Копирование прошлой недели, другой недели, шаблона и черновик из Spec 003 копируют заметки дней **со снятыми галочками**. «Сохранить как шаблон» сохраняет и заметки.
- Исходная неделя при копировании не меняется: её заметки и галочки остаются историей.
- Замок прошедших дней из Spec 003 касается наличия дня в плане. Галочки и текст заметки прошедшего дня редактируются (поздняя отметка честна, как и отметка прошлого дня в v0.1).

## Настройки

У практики два новых переключателя: «Показывать заметку целиком» и «Отметка по чеклисту».

## Критерии приёмки

- [ ] В редакторе плана у каждого запланированного дня пишется своя заметка; семь дней питания составляются без выхода из планирования.
- [ ] На «Сегодня» сегодняшний «План дня» виден целиком с форматированием; галочки отмечаются на карточке одним тапом.
- [ ] При отметке по чеклисту кубик дня меняется сам по таблице и сразу виден в «Неделе» и «Всё».
- [ ] Копирование недели и шаблон переносят заметки дней с чистыми галочками; исходная неделя не меняется.
- [ ] Практики без новых настроек работают точно как до этой спеки.
- [ ] Светлая и тёмная тема читаемы, включая зачёркнутые пункты и выделение цветом на карточке.

## Вне объёма

Трапезы и пункты как отдельные объекты, калории и пищевые данные, напоминания о трапезах, редактирование текста прямо внутри карточки.
