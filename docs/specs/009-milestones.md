# Spec 009 — Майлстоны: сущность и связь с ежедневным действием

Копия вкладки «Spec 009» рабочего канала (2026-11-16).

## Проблема

Смысл приложения — цепочка «действие → майлстон → цель». На «Сегодня» её не видно: карточка говорит, что делать, но не говорит, к чему это ведёт. А сам майлстон сейчас — пустой текст у цели, без срока, критерия и прогресса. Вываливать всё в раскрытую карточку нельзя — перегруз экрана.

## Решение: три слоя показа

1. **Постоянно и тихо** — микрострока на карточке: цель и срок.
2. **В момент действия** — вспышка прогресса при отметке.
3. **По запросу** — лист цели со всеми подробностями.

## Часть A — сущность «Майлстон»

| Поле | Значение |
| --- | --- |
| goal_id | цель; у цели один открытый майлстон, закрытые — история |
| title | короткое имя для микростроки и вспышки, до ~30 символов («Разговор 15 мин») |
| criterion | как продемонстрировать, что достигнут — да/нет; формат редактора из Spec 005 |
| due_date | дата проверки |
| start_date | дата начала (по умолчанию — день создания), нужна для темпа |
| budget_kind | `none` / `sessions` (число дней с отметкой ≥ min любой практики цели) / `amount` (сумма amount практик цели с выбранной единицей) |
| budget_unit, budget_target | для `amount`: единица и цель («мин», 720); для `sessions`: цель в занятиях; показ минут от 60 — в часах |
| status | `open` / `achieved` / `missed` / `dropped` |
| closed_at, review_note | когда и с каким выводом закрыт |

- **Прогресс** = сумма отметок практик цели с start_date по сегодня по правилу budget_kind. Не хранится, считается.
- **Темп:** ожидаемое к сегодня = target × (прошло дней / всего дней). Разница — «опережаешь / отстаёшь на X». Без красного, норма практик автоматически не меняется (правило концепции).
- Старое текстовое поле майлстона у цели мигрируется: непустой текст → открытый майлстон с этим criterion, без срока. Резервная копия перед миграцией.

## Часть B — микрострока на карточке

Под названием практики вместо имени цели: `Итальянский · [флажок] 6 нед`.

- Остаток: «6 нед», меньше двух недель — «9 дн», в день срока — «сегодня», после — «проверить» (нейтрально, не красным).
- Нет открытого майлстона — приглушённое «· нет майлстона». Это и есть мягкое напоминание, о котором договаривались раньше.
- Тап по микростроке открывает лист цели (часть D) и не раскрывает карточку.
- Та же микрострока — в заголовках целей на «Неделе» и «Всём».

## Часть C — вспышка при отметке

После отметки чекбоксом (или самой галочки чеклиста, закрывшей практику) — нижний toast на 2,5 с, не блокирующий:

- с бюджетом: `+15 мин → Разговор 15 мин · 5 из 12 ч`;
- без бюджета: `→ Разговор 15 мин · 6 нед`;
- без майлстона — вспышки нет;
- если отметка довела прогресс до target — `Бюджет майлстона набран — проверишь себя?` со ссылкой на проверку.

Тап по toast открывает лист цели. Снятие отметки вспышку не показывает.

## Часть D — лист цели

**Уточнение владельца (2026-11-15):** отдельного листа цели нет. Везде в этой спеке «лист цели» — это **экран цели** из новых настроек, на который ведёт тап по названию цели на карточке (задача 18). Блоки ниже добавляются на этот экран: майлстон, прогресс, история.

Открывается из микростроки, из toast и иконкой-флажком в ряду иконок раскрытой карточки (рядом с заметками и звездой из задачи 13).

| Блок | Содержание |
| --- | --- |
| Шапка | цель, категория, направление («зачем»), если заполнено |
| Майлстон | title, критерий, срок и остаток |
| Прогресс | полоса с отметкой ожидаемого темпа и строка «опережаешь / отстаёшь на X»; без бюджета — только время |
| Практики цели | список с вкладом каждой в прогресс |
| История | прошлые майлстоны со статусом и датой |
| Действия | «Изменить», «Проверить сейчас», «Новый майлстон» (если нет открытого) |

Создание и редактирование майлстона также на экране цели в новых настройках. В форме — подсказка к критерию: «Как ты поймёшь, что дошёл? Ответ — да или нет», и к сроку: «обычно 1–3 месяца».

## Часть E — проверка в срок

- В день due_date и после наверху «Сегодня» одна мягкая карточка: «Майлстон «Разговор 15 мин» — срок. Достигнут?» и критерий. Несколько срочных — по одной за раз.
- **Да** → статус `achieved`, короткое поздравление без фейерверков и предложение «Поставить следующий».
- **Нет** → статус `missed` и один вопрос-диагностика из концепции с четырьмя ответами: «делал регулярно, но не то…», «делал редко…», «планка была слишком высокая», «цель больше не важна»; ответ пишется в review_note. Затем «Новый срок» (тот же майлстон снова открыт) или «Новый майлстон».
- **Позже** → карточка скрывается до завтра; микрострока продолжает показывать «проверить».
- Никаких уведомлений и красного.

## Критерии приёмки

- [ ] Майлстон создаётся с критерием, сроком и бюджетом или без него; старый текст майлстона перенесён.
- [ ] На всех карточках «Сегодня» видна микрострока цели со сроком или «нет майлстона»; тап открывает лист цели.
- [ ] После отметки появляется вспышка с правильным прогрессом и не мешает следующей отметке.
- [ ] Лист цели показывает прогресс, темп и историю.
- [ ] В день срока появляется карточка проверки; «Да», «Нет» и «Позже» работают как описано.
- [ ] Экран «Сегодня» не стал плотнее: высота свёрнутой карточки не выросла.

## Вне объёма

Проекты и шаги с дедлайнами (отдельная спека); связь майлстона с планированием недели («нужно ~3 занятия, запланировано 2») — следующим шагом; приоритет по отставанию в строке «В приоритете»; AI-помощь в формулировке.
