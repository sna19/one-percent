# Spec 002 — составные строки: цели и формат

> Копия вкладки «Spec 002» рабочего канала (https://claude.ai/artifact/17433pk2Ek3UGUh1LBUofq), снята 2026-11-08 (rev 1).

## Как пользоваться этой спекой

Задача для Claude Code после v0.1. Сохрани спеку в `docs/specs/002-goal-rows-and-format-lens.md`, работай маленькими коммитами, решения — в `docs/DECISIONS.md`. Шаг «Миграция данных» сначала покажи владельцу в «Диалоге» и дождись подтверждения.

## Проблема (из первого дня использования)

В трекере восемь практик — восемь строк. Счёт дня «2/8» выглядит как провал, хотя день был нормальный. Тренажёрка и аэробика — альтернативы, а не обе в один день, поэтому «полный день» почти недостижим. Экран растёт с каждой новой практикой.

## Решение

- **Строка = цель.** Практики одной цели собираются в одну строку, которая раскрывается по тапу.
- **Вторая линза — по формату.** У практики есть метка формата (аудиокниги, практика языка, чтение, спорт). Переключатель «По целям / По формату» меняет только группировку строк; отметки общие.
- **Счёт дня — всегда по целям.**

## Модель данных

| Изменение | Поля | Заметки |
| --- | --- | --- |
| Новая сущность Format | name, order, archived | создаются и переименовываются в настройках |
| Practice + format | format_id, необязательно | практика без формата — группа «Без формата» в линзе формата |
| Practice в цели | goal_id уже есть | у цели может быть несколько практик |

Начальные форматы: «Практика языка», «Аудиокниги», «Чтение», «Спорт».

## Миграция данных

Сейчас у каждой практики, вероятно, своя цель. Предложи владельцу перегруппировку и примени после подтверждения:

| Цель | Практики (новое короткое имя) | Формат |
| --- | --- | --- |
| Итальянский | Практика; Аудиокнига | Практика языка; Аудиокниги |
| Английский | Чтение вслух; Аудиокнига | Практика языка; Аудиокниги |
| Иврит | Аудиокнига | Аудиокниги |
| Чтение HBR | HBR | Чтение |
| Спорт | Тренажёрка; Аэробика | Спорт |

История отметок сохраняется полностью: меняются только связи практик с целями и имена.

> **Сделано 2026-11-08:** владелец перегруппировал практики сам в настройках (цель, имя, формат у каждой практики). Миграция данных кодом не писалась.

## Экран

- Над неделей переключатель «По целям / По формату»; выбор запоминается на устройстве.
- Группа из одной практики выглядит и работает как в v0.1.
- Группа из нескольких практик: имя, шеврон и число практик. Тап по имени раскрывает или сворачивает; раскрытые строки практик идут с отступом и отмечаются как в v0.1 (тап — норма, долгое нажатие — выбор). Раскрытые группы запоминаются на устройстве.
- Тап по клетке свёрнутой группы раскрывает её, а не ставит отметку: иначе неясно, какую практику отметить.

## Правила расчёта

- Глубина клетки свёрнутой группы = максимальная глубина её практик за день.
- Если за день сделано больше одной практики группы (≥ min_dose), в углу клетки число сделанных.
- «N дней без» для группы = дней с последней отметки любой её практики ≥ min_dose; для практики внутри — как в v0.1.
- Подсказка «Сегодня в приоритете» выбирает среди целей, в обеих линзах.
- Счёт дня: целей, у которых хотя бы одна практика ≥ min_dose, из активных целей. Например, «2 из 5».

## Настройки

- У практики выбор цели и формата.
- Форматы: создать, переименовать, архивировать, порядок.

## Критерии приёмки

- [x] Миграция подтверждена владельцем, применена, история отметок не потеряна. (Перегруппировка вручную в настройках.)
- [ ] В линзе по целям пять строк; группы раскрываются и сворачиваются тапом, состояние сохраняется после перезагрузки.
- [ ] Отметка внутри раскрытой группы сразу меняет и строку практики, и свёрнутую клетку группы.
- [ ] Счёт дня считается по целям и одинаков в обеих линзах.
- [ ] Линза по формату показывает те же отметки, сгруппированные по формату; выбор линзы сохраняется.
- [ ] Светлая и тёмная тема читаемы, включая число в углу клетки.
