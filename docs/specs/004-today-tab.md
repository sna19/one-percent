# Spec 004 — вкладка «Сегодня» и три вкладки

> Копия вкладки «Spec 004» рабочего канала (https://claude.ai/artifact/17433pk2Ek3UGUh1LBUofq), снята 2026-11-09 (rev 1).

## Как пользоваться этой спекой

Задача для Claude Code после Spec 003. Сохрани спеку в `docs/specs/004-today-tab.md`, работай маленькими коммитами, решения — в `docs/DECISIONS.md`. Модель данных не меняется: экран строится на плане (Spec 003) и отметках.

## Проблема (из использования)

Недельная вкладка «План» работает, но она перегружена для ежедневного использования: строки целей, раскрытые практики, контуры на всю неделю. В течение дня нужен ответ на один вопрос — что сегодня сделать и отметить. Недельная сетка — это обзор, а не рабочий экран.

## Решение

- Новая вкладка **«Сегодня»** — рабочий экран по умолчанию: только запланированное на сегодня, карточками.
- Вкладок становится три: **«Сегодня»**, **«Неделя»** (нынешний «План» без изменений), **«Всё»** (переключатель «По целям / По формату» уходит внутрь этой вкладки).

## Экран «Сегодня»

| Зона | Содержание |
| --- | --- |
| Шапка | дата (например «Пн, 9 ноября») и счёт «по плану X из Y» на сегодня |
| Приоритет | «В приоритете: <цель>» среди невыполненного плана на сегодня; если всё сделано — «План на сегодня выполнен» |
| К выполнению | карточки запланированных на сегодня и ещё не сделанных практик |
| Сделано | карточки сделанного сегодня — и по плану, и бонусы (с меткой «бонус») |
| Сделать что-то ещё | свёрнутый список остальных активных практик; тап отмечает бонус |

Карточка: контур цвета категории; слева квадрат-отметка; название практики, под ним цель; справа подсказка дозы («норма 15 мин», при наличии минимума можно «мин 5 · норма 15»). Сделанная карточка — заливка цвета категории с глубиной по правилам v0.1, белый текст.

## Поведение

- Тап по карточке ставит норму, как тап по клетке сегодня в v0.1; повторный тап очищает отметку.
- Долгое нажатие — тот же выбор, что в v0.1: минимум, норма, точное количество, очистить.
- Отмеченная карточка уезжает в «Сделано» с короткой анимацией; отмена возвращает её обратно.
- Нет плана на сегодня (выходной от плана или план пуст): вместо списка — фраза «На сегодня ничего не запланировано» и раскрытое «Сделать что-то ещё».
- Нет утверждённого плана на неделю: работает черновик по правилам Spec 003, плашка черновика показывается и здесь.
- Вкладка по умолчанию при открытии приложения — «Сегодня»; последняя выбранная вкладка не запоминается, чтобы утро всегда начиналось с рабочего экрана.

## Критерии приёмки

- [ ] Приложение открывается на вкладке «Сегодня»; вкладок три: «Сегодня», «Неделя», «Всё».
- [ ] На «Сегодня» видны только запланированные на сегодня практики; сделанное — в «Сделано», бонусы с меткой.
- [ ] Тап и долгое нажатие на карточке работают как на клетке в v0.1, отметка сразу видна и во вкладке «Неделя».
- [ ] «Сделать что-то ещё» отмечает бонус, и он появляется в «Сделано».
- [ ] Переключатель «По целям / По формату» работает внутри вкладки «Всё».
- [ ] Пустой план на сегодня показывается понятно, без пустого экрана.
- [ ] Светлая и тёмная тема читаемы на iPhone, включая белый текст на заливке.
