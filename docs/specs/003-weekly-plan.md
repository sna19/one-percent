# Spec 003 — недельный план

> Копия вкладки «Spec 003» рабочего канала (https://claude.ai/artifact/17433pk2Ek3UGUh1LBUofq), снята 2026-11-09 (rev 1).

## Как пользоваться этой спекой

Задача для Claude Code после Spec 002. Сохрани спеку в `docs/specs/003-weekly-plan.md`, работай маленькими коммитами, решения — в `docs/DECISIONS.md`. Эта спека заменяет отдельное «расписание по дням» из бэклога v0.2: допустимые дни задачи становятся шаблоном для планирования.

## Проблема (из использования)

Практик стало много (только в «Спорте» шесть), и экран превратился в хаос. Многие задачи не ежедневные: пианино возможно только в понедельник, пятницу и субботу, и показывать его каждый день бессмысленно. Счёт дня по всем задачам нечестен.

## Решение

- **Недельный план по дням:** владелец выбирает, какие практики в какие дни недели он планирует.
- **Контур = план, заливка = факт.** Невыполненный план остаётся контуром, без красного.
- **Вкладка «План»** слева от «По целям» и «По формату», открывается по умолчанию. Две другие остаются полным обзором.
- **Источник плана выбирается:** как прошлая неделя (по умолчанию), с нуля, любая прошлая неделя, шаблон с именем.
- **Автопродление создаёт черновик,** а не готовый план.

## Модель данных

| Сущность | Поля | Заметки |
| --- | --- | --- |
| WeekPlan | week_start, status (`draft` / `confirmed`), source (`previous` / `empty` / `week:<дата>` / `template:<id>`), confirmed_at | один план на неделю |
| PlanItem | week_plan, practice, date | уникально по паре практика + дата |
| PlanTemplate | name, items (practice + день недели), archived | например «Обычная неделя», «Неделя со сменами» |
| Practice + default_days | дни недели, необязательно | шаблон дней практики, например пианино: пн, пт, сб |

## Экран планирования

1. **Источник.** Кнопки: «Как прошлая неделя», «С нуля», «Шаблон» (список имён), «Другая неделя» (список прошлых недель с итогом «по плану X из Y»).
2. **Редактор.** Сетка практики × дни, сгруппированная по целям; тап по клетке включает и выключает план. Быстрые действия строки: «каждый день», «по шаблону практики» (default_days), «очистить». Счётчик: сколько практик и занятий запланировано.
3. **Подтверждение.** Кнопка «Утвердить план» и необязательное «Сохранить как шаблон» с именем.

Мягкое предупреждение, если практик в плане больше лимита из настроек: не запрет, а фраза вроде «В плане 11 практик. Это реалистично?». Цель: весь цикл планирования за минуту.

## Вкладка «План»

- Строки — цели, у которых есть практики в плане недели (правила составной строки — как в Spec 002, внутри только запланированные практики).
- Запланированная клетка — контур; сделано — заливка по глубине; день без плана — пустое место без рамки.
- **Бонус:** практика, сделанная без плана, засчитывается и показывается заливкой с маленькой меткой; её цель появляется во вкладке до конца недели.
- Счёт дня: сделано из запланированного на этот день (по целям). Итог недели внизу: «по плану X из Y, бонусов Z».
- «Сегодня в приоритете» выбирает среди запланированного на сегодня.
- Кнопка «Изменить план» открывает редактор текущей недели.

## Правила

- **Автопродление:** если на начало недели нет утверждённого плана, создаётся черновик по прошлой неделе (а если её нет — по default_days). Во вкладке «План» над сеткой плашка: «Черновик по прошлой неделе» с кнопками «Утвердить» и «Спланировать иначе». Черновик сразу работает как план.
- **Прошедшие дни плана не редактируются:** снять план с прошедшего дня значило бы скрыть пропуск. Сегодня и будущие дни — в любой момент.
- Архивная практика при копировании плана или шаблона пропускается.
- Вкладки «По целям» и «По формату» тоже показывают контур запланированных клеток, но счёт дня в них остаётся как в Spec 002.

## Критерии приёмки

- [ ] План на неделю составляется из любого источника: прошлая неделя, с нуля, другая неделя, шаблон.
- [ ] Шаблон сохраняется с именем и применяется к новой неделе.
- [ ] Без утверждённого плана во вкладке «План» виден черновик и плашка с двумя кнопками.
- [ ] Пианино с default_days пн/пт/сб при «по шаблону практики» попадает ровно в эти дни; во вторник его нет в счёте дня.
- [ ] Незапланированная отметка показывается как бонус и учитывается в итоге недели.
- [ ] Прошедшие дни плана не редактируются, сегодня и будущие — да.
- [ ] Планирование недели из шаблона с двумя правками занимает у владельца на iPhone не больше минуты.
