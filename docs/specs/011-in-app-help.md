# Spec 011 — Справка в приложении

Копия вкладки «Spec 011» рабочего канала (2026-11-15).

## Как пользоваться этой спекой

Задача для Claude Code после задачи 10 (нужна верхняя панель из Spec 007). Сохрани спеку в `docs/specs/011-in-app-help.md`. Тексты справки ниже — стартовая версия: сверь их с тем, как экраны реально работают, исправь неточности и перечисли их в «Диалоге».

## Зачем

Функций стало много, часть управления — иконки без текста. Владелец хочет быстро вспомнить, как работает каждый экран, не выходя из приложения.

## Как выглядит

- **Иконка «?» в кружке рядом с крупным заголовком экрана** (и в сжатом заголовке при прокрутке). В правую часть панели не ставим — там лимит две иконки + «⋯». Пункт «Справка» дублируется в меню «⋯». Иконка спокойная, вторичного цвета; `aria-label="Справка"`.
- **Тап открывает нижний лист** со справкой этого экрана: заголовок, одна фраза «для чего этот экран», затем список «иконка → что делает» с настоящими иконками приложения, затем «Жесты» и «Правила». Укладывается в один экран телефона.
- Внизу листа ссылка **«Словарь»** — один общий лист терминов (ниже).
- Тексты живут в Markdown-файлах `src/lib/help/<экран>.md` и рендерятся санитизированным Markdown. Иконки в тексте — через короткий тег вроде `:icon-star:`, который подставляет ту же иконку, что в интерфейсе.
- Работает без сети (файлы входят в сборку).

## Правило на будущее

**Справка — часть Definition of Done.** Любая задача, которая добавляет или меняет экран, кнопку, иконку или жест, обновляет файл справки этого экрана в том же коммите. Claude (чат) в новых спеках пишет раздел «Справка» с готовым текстом. Правило записано во вкладке «Протокол».

## Стартовые тексты

Стартовые тексты для экранов «Сегодня», «Неделя», «Редактор плана», «Всё», «Настройки», «Экран практики», «Редактор заметки» и «Словарь» — во вкладке канала. В репозитории они заменены сверенными версиями: `src/lib/help/*.md`. Расхождения перечислены в «Диалоге» (2026-11-15).

### Входящие, Итоги недели, Майлстоны

Тексты пишутся вместе с реализацией задач 14, 15 и 16 по правилу выше, на основе их спек.

## Критерии приёмки

- [ ] На каждом экране есть «?» рядом с заголовком и пункт «Справка» в «⋯»; справка открывается без сети.
- [ ] Иконки в справке — те же, что в интерфейсе.
- [ ] Тексты сверены с реальным поведением; расхождения перечислены в «Диалоге».
- [ ] Справка любого экрана умещается в один экран iPhone; светлая и тёмная тема читаемы.
- [ ] Правило «справка в том же коммите» записано в `CLAUDE.md`.

## Вне объёма

Онбординг-тур, подсказки при первом запуске, поиск по справке, видео.

## Что обновить в репозитории

- `docs/specs/011-in-app-help.md` — эта спека.
- `src/lib/help/*.md` — тексты справки.
- `CLAUDE.md` — правило Definition of Done про справку.
- `docs/DECISIONS.md` — «?» у заголовка, тексты в Markdown, справка как часть готовности задачи.
