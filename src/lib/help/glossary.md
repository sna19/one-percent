# Словарь

| Термин | Значение |
| --- | --- |
| Категория | область жизни и цвет: Развитие, Здоровье… |
| Цель | куда ты идёшь: «Итальянский» |
| Образ цели | иконка, эмодзи или буквы на цвете категории |
| Вложено | всё время (или дни) в цель за всё время |
| Майлстон | проверяемая точка цели со сроком |
| Практика | регулярное действие для цели с дозой |
| Ссылки | вкладка-лаунчер: ссылки из заметок отмеченных практик |
| Навигатор | дерево категория › цель › практика с поиском и фильтрами — везде, где показываются или выбираются практики |
| Объём | у практики с концом (книга): всего и где ты сейчас |
| Формат | способ действия: аудиокниги, практика, чтение… |
| Минимум / норма | полкубика / полный кубик |
| План | что и в какие дни на этой неделе |
| Шаблон недели | сохранённая заготовка плана |
| Бонус | сделано вне плана — засчитывается |
| Заметка «Всегда» | одна на практику, для всех дней |
| Вкладка | раздел внизу экрана; помнит, где ты был |
| Входящие | записанные мысли, ещё не разобранные |
| Заметка дня | своя на каждый запланированный день |
| Фокус недели | ★ у цели: до трёх целей, ради которых планируется неделя |
| Итоги недели | что отклонилось от обычного; хранится только ретро |
| Пауза по плану | неделя, когда цели нет в плане: «N дней без» стоит |
