# Ссылки

Быстрые переходы: ссылки из заметок отмеченных практик на одном экране, один тап — сайт.

## Иконки
- :icon-link: в раскрытой карточке или «В „Ссылках“» на экране практики — её ссылки из заметки «Всегда» появятся здесь.
- Кружок с плюсом справа — добавить практику через навигатор. :icon-grip: — «Порядок»: перетащи группы за :icon-grip:.
- Название группы — экран практики; тап по шеврону сворачивает группу (запоминается).

## Правила
- Ссылки читаются из заметки «Всегда» — поправь заметку, и вкладка поменяется сама. Заметки дня не учитываются.
- Поиск появляется, когда ссылок больше десяти.
- «Все практики» (прежняя вкладка «Всё») — в «⋯» и в конце «Целей».
