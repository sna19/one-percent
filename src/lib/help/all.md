# Все практики

Обзор всех активных практик, включая незапланированные. Открывается из «⋯» и строкой в конце «Целей».

## Иконки
- :icon-target: / :icon-shapes: — группировать по целям («зачем») или по форматам («каким способом»). По форматам виден перекос, например много аудиокниг и мало практики.
- :icon-settings: — настройки. :icon-plus: — записать во входящие. :icon-left: :icon-right: — другая неделя.

## Жесты
- **Тап по клетке** — отметить норму. **Долгое нажатие** — лист с дозой и заметкой. Название практики — её экран, день в шапке — «Сегодня».
- **Тап по группе** — раскрыть её практики.

## Правила
- По целям: сверху «★ Рекомендованные» — цели с практикой под звездой, ниже категории, как в настройках. Тап по заголовку сворачивает раздел, это запоминается. Поиск — по практике, цели, категории или формату.
- Строка «День» — счёт всегда по целям: сколько целей сделано из всех активных.
