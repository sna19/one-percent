# План недели

Составить неделю за минуту.

## Шаги
- **0. Входящие** — если есть неразобранное, сверху плашка «разобрать».
- **1. Источник** — как прошлая неделя, с нуля, шаблон недели или другая неделя.
- **2. Редактор** — тап по пустой клетке планирует день; по запланированной — «Заметка дня» или «Убрать из плана». Строчки в клетке — есть заметка дня. У строки: «каждый день», «обычные дни», «очистить».
- **Фокус недели** — до трёх целей из плана; в итогах они первые.
- **3. Утвердить**, по желанию — «Сохранить как шаблон недели», новый или вместо старого.

## Иконки
- :icon-more: — «Шаблоны недели» (имя, удаление, порядок за :icon-grip:) и «Новая неделя с нуля».

## Правила
- Без утверждения работает черновик по прошлой неделе.
- Прошедшие дни не меняются.
- Больше практик, чем мягкий лимит, — вопрос «Это реалистично?».
