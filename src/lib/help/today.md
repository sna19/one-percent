# Сегодня

Дела дня по плану недели.

## Иконки
- :icon-check: — норма; ещё раз — снять. От минимума карточка уходит в «Сделано».
- **Мин · Норма** — полкубика или полный, **±** — своё количество.
- :icon-note: — заметка «Всегда», :icon-day: — заметка дня; бледная — ещё нет.
- :icon-star: — первой в «Сделать что-то ещё» (вне плана, засчитывается бонусом).
- :icon-more: на карточке — лист с дозой и заметкой. :icon-grip: — «Порядок»: тащи карточки, затем «Готово».
- :icon-settings: — настройки, :icon-more: вверху — «Изменить план».

## Жесты
- Тап по карточке — раскрыть, одна за раз.
- :icon-left: :icon-right: или свайп — другой день этой и следующей недели.

## Правила
- Будущий день: заметка дня и состав плана, без отметок. Прошедший: отметки, без смены плана.
- **В приоритете** — цель плана, дольше всех без отметки; недели паузы по плану не считаются.
- Нет квадрата — отметка по чеклисту заметки дня. См. [Редактор заметки](help:note).
