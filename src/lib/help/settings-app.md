# Приложение

Правила самого приложения в одном месте: лимиты, сроки и пороги, которые раньше были зашиты в код. У каждого — :icon-help: с объяснением: что меняет, почему такое значение по умолчанию и где виден эффект.

## Как менять
- **− / +** — шаг на единицу; диапазон ограничен, свободного ввода нет.
- Выбор из вариантов — тапом.
- **Сбросить к умолчанию** — появляется, когда значение изменено.

## Что здесь
- **Общее** — с какого дня начинается неделя (пока только показывается).
- **Входящие** — когда запись и шаг получают метку возраста; сколько дней видна история разобранного.
- **Сегодня** — сколько строк «Шагов» наверху, сколько держится вспышка после отметки.
- **Неделя и итоги** — перегруз дня в плане, мягкий лимит практик недели, строки блоков итогов, когда шаг попадает в итоги как застрявший.
- **Цели** — сколько целей можно отметить ★ на неделю. Если уменьшить ниже числа ★, приложение спросит, какие снять.

Настроек, которые ломают сам подход — красный цвет, серии без пропусков, автоповышение нормы, — здесь нет намеренно.
