# Редактор заметки

Заметка «Всегда» :icon-note: — одна на практику. Заметка дня :icon-day: — своя на каждый день в плане.

## Кнопки
- **B I U** — жирный, курсив, подчёркнутый. **A** — выделение цветом.
- **•** — список. **☑** — чеклист.
- :icon-link: — ссылка: выдели текст — он станет названием. Тап по ссылке в редакторе — «Открыть / Изменить / Убрать».
- **Всегда / день** вверху — переключиться на другую заметку практики.
- **⤢** — редактор на весь экран, «Готово» — обратно. Тот же редактор — у «Зачем» цели и «Критерия» майлстона.

## Правила
- Сохраняется само.
- **Первый абзац** (до Enter) виден на свёрнутой карточке — начинай с сути.
- Галочки заметки «Всегда» не сбрасываются; в заметках дня новой недели они чистые.
