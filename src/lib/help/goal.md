# Цель

Куда ты идёшь и ближайшая проверяемая точка. Поля сохраняются сами.

## Майлстон :icon-flag:
- Один открытый на цель: коротко (для карточки), критерий «да / нет», начало и срок, бюджет — без него, занятия (дни с отметкой) или количество (минуты, страницы…).
- **Полоса** — сколько набрано; черта — где был бы ровный темп к сегодняшнему дню. «Опережаешь / отстаёшь» — без давления, норма сама не меняется.
- **Проверить сейчас** — «Достигнут?»: «Да» закрывает; «Нет» — вопрос «что помешало?», затем новый срок или новый майлстон.
