# Цели

Все твои цели в одном месте.

## Иконки
- Листай ленты вбок; тап по цели — её экран, «‹ Цели» вернёт на ту же карточку.
- :icon-flag: — текущий майлстон и срок; полоса — его прогресс, если есть бюджет.
- **Точки** — эта неделя: день закрашен, если сделана хоть одна практика цели. Бледные с подписью «на паузе» — цели нет в плане недели.
- **Вложено** — всё за всё время: часы, если практики в минутах, иначе дни с отметкой. Никогда не уменьшается.
- :icon-badge-check: — достигнутые майлстоны.
- :icon-plus: слева — во входящие, кружок с плюсом справа — новая цель.

## Правила
- Образ цели меняется на её экране: иконка, эмодзи или буквы.
- **Пройденный путь** внизу — цели из архива, приглушённые, с датой.
- Без очков, уровней и стриков: только настоящее — вложенное время и майлстоны.
